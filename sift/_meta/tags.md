# Tags

Controlled vocabulary for wiki page tags. When tagging a page, use existing tags when
they fit. Propose new tags here if no existing tag covers the concept.

| Tag | Description |
|-----|-------------|
| `architecture` | System design, data flow, service boundaries, ADRs |
| `frontend` | React/TypeScript web application, UI components, state management |
| `backend` | Go and Rust services, API layer, server-side logic |
| `data-pipeline` | Ingest, streaming, batch processing, data flow from source to storage |
| `charts` | Timeseries charts, visualization, Legend, chart components |
| `testing` | Test infrastructure, test patterns, vitest, coverage |
| `operations` | CI/CD, deployment, monitoring, incidents, runbooks |
| `tooling` | Developer tools, build system, code generation, linting |
| `infrastructure` | Kubernetes, cloud resources, databases, storage |
| `performance` | Performance patterns, optimization, profiling, 60fps rendering |
| `routing` | URL routing, navigation, TanStack Router, URL state sync |
| `styling` | CSS, Tailwind, Radix UI Themes, theming, colors |
| `domain-concepts` | Business domain terminology, product concepts, user-facing features |
| `chat` | Chat service, LLM gateway, AI message streaming, tool use, reactor |
| `agents` | Autonomous coding agents and agent harnesses: SCV, eval runners, agent skills |
